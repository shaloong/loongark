# 当前能力与限制

面向选型与接入的当前概览；日常开发在 develop，默认分支和正式 Storybook 为 main。开发提交不会自动发布 npm 或覆盖正式展示。

## 组件与高级能力

当前目录覆盖119个组件族。React、Vue、Solid、Svelte 保持相同公开值入口，框架事件和绑定语法各自保留。Storybook 的组件 Docs 提供同场景四端完整代码、引用文件、真实类型与默认值来源、可操作的状态 Story 和组合场景选择。

| 方向 | 已实现 | 使用边界 |
| --- | --- | --- |
| 常规组件 | 布局、排版、按钮、输入、选择、反馈、导航、日期、弹层与 Ark 原生部件 | 原生语义优先；受控状态使用所在框架的事件/绑定方式。默认黑白灰，品牌色作为显式强调。 |
| 表格 | 排序/多列排序、列筛选、查询、分页、选择、分组聚合、树行、冻结列、列排序/缩放、单元格编辑、范围选择、批量粘贴和多级撤销 | 稳定行/列 key 必须由调用方维护；数据获取、权限及批量提交业务由应用负责。 |
| 编辑器 | 独立 CodeMirror 代码编辑器、ProseMirror 富文本、表格/列表/链接、历史、扩展、表单回退 | 不提供文件存储或协同服务；富文本只接收支持的结构，拒绝危险链接和无效节点。图片上传属于外部契约。 |
| 图表 | 折线、柱状、面积、堆叠、饼图、散点；时间/对数轴、图例、缩放/刷选、检查与键盘导航 | 不是任意图形绘制或 GIS 引擎；对数轴须使用合法正值，非法配置按模型契约处理。 |
| 问卷 | 条件显示、异步校验、矩阵单选/多选、排序拖动与按钮操作、重复组、自定义题型渲染 | 题型定义与持久化由应用提供；异步返回、受控拒绝和稳定题目 ID 按公开契约处理。 |
| 虚拟化 | 表格/消息可变行高、横向列窗口、二维网格、虚拟瀑布流、焦点项保留和键盘编辑模式 | SSR 输出有界初始窗口；服务端没有真实字体与容器测量，客户端挂载后校正。 |
| 日期/触摸 | 本地化文本解析、日期时间组合、Drawer 全方向、RTL、指针拖动与焦点恢复 | 不把模拟触摸、缩小视口或桌面 Safari 当作真实手机键盘与触摸通过。 |

## 默认视觉与输入状态

共享 Token 管理控件高度、内外间距、图标、圆角、边框与焦点。密码输入的显式 `disabled=false` 不应显示禁止指针；复选框选中 hover 保持语义主色中性背景；原生单选下拉使用统一 Lucide 箭头及逻辑方向留白，多选保留原生列表，强制颜色模式恢复系统箭头。

Tour 保留 Ark 的结束契约，不强制选择业务流程的下一焦点。四端组合与 WithFocusReturn Story 使用 onStatusChange 返回启动按钮，取消卸载后的待执行帧，并尊重应用已经移动的焦点。

默认、hover、focus、disabled、loading、invalid、空状态在 Story 中分别展示。Story args 是演示配置；API 表区分适配层实际缺省值、公开类型注释与“未指定”。未指定值由共享模型、上下文或原生行为处理，不意味着 false；示例数据也不是组件自动提供的业务默认值。

## 验证范围

| 项目 | 当前证据 | 限制 |
| --- | --- | --- |
| Linux Chromium / Firefox / WebKit | 四端消费、Story 交互、表单、焦点、窄屏明暗及专项回归 | 实际结果以对应源码提交的 CI 为准；WebKit 不等于原生 Safari。 |
| macOS Safari | 独立 safaridriver 工作流与既有 P0 验收 | Linux 无法代替当前提交的原生 Safari；以该提交的远程任务结果为准。 |
| 视觉基线 | 已审阅 Linux 与 Windows 分开保存 | 不覆盖 Windows 截图，不使用更新基线掩盖回归。 |
| 辅助使用 | Axe/语义树、键盘、强制颜色、两倍排版 Token、视口和组合事务模拟 | 真实屏幕阅读器、iOS/Android 和原生系统输入法尚未验收。 |
| 性能 | 生产包体/压缩、编辑器延迟块、SSR、实际大数据滚动与20次重复挂载 | 数字属于所记录 Linux 环境；不是所有设备的 SLA，也不是完整堆泄漏证明。 |
