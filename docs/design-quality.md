# 组件视觉与交互规范

默认界面以中性色表达层次，Shaloong VI 用于明确的品牌强调；参考 shadcn 的密度与留白、MUI 的状态处理，不复制外部调色板。颜色和尺寸定义见 [主题系统](theme-system.md)。

## 布局与状态

- 标签、说明与输入保持统一纵向间距；前后缀、图标按钮与正文按视觉中心对齐。
- 控件外框、hover、focus、invalid 使用同一可见边界，焦点指示不能缩进到输入框内部。
- 默认、选中、禁用、只读、加载、错误和空态都有明确语义；cursor 与实际可操作性一致，不能因 `disabled=false` 显示禁止状态。
- 中性主题的 Checkbox 选中 hover 使用语义主色；品牌主题由 Token 明确覆盖。展开与下拉箭头统一使用 Lucide。
- 支持长文案、RTL 与窄屏；按钮文案可换行，原生 Select 箭头有逻辑方向留白，表头与单元格使用相同逻辑对齐。

## 交互与可访问性

保留原生表单关联、可访问名称、错误说明、键盘和焦点恢复；装饰图标隐藏于可访问树。使用 transform/opacity 动效并尊重 `prefers-reduced-motion`。高对比模式不只依赖颜色区分状态，保留系统色、边框和焦点轮廓。

虚拟组件的行列尺寸由调用方配置，不能因内容被虚拟化就移除焦点或键盘入口；高级边界见 [说明](advanced-boundaries.md)。

## 如何验证

先完成构建与交互回归，再实际查看桌面/375px、浅色/深色截图；检查布局、指针、焦点、状态和浮层。自动比较与 Axe 补充人工观察，不能替代全部体验检查。基线按平台独立审阅，不用更新截图掩盖回归。测试与产物约定见 [贡献指南](../CONTRIBUTING.md)。
