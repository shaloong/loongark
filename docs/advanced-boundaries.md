# 高级组件边界与辅助使用

组件侧契约包括：组合输入、连续操作、受控拒绝、异步失效、数据变化与生命周期。业务持久化、权限、表单内容和远程数据仍由调用方实现。

| 组件 | 契约与回归 |
| --- | --- |
| DataTable | 组合输入中的 Enter/Escape 和确认阶段 keyCode=229 不保存、取消、移动范围或操作历史；完成组合后原快捷键生效。列排序的组合取消键保留预览会话。现有异步保存取消、晚到结果、批量原子校验、多级历史、数据删除与受控回退回归继续执行。 |
| CodeEditor / RichTextEditor | 沿用 CodeMirror / ProseMirror 的组合输入模型，禁止替换成自制 contenteditable。浏览器组合事务提交中文，再验证受控拒绝恢复已接受内容并保留焦点。链接面板组合确认不提交或关闭，正常 Escape 恢复编辑区焦点。已有只读即时阻断、异步装载取消和插件卸载回归。 |
| VirtualGrid / VirtualMasonry / 表格窗口 | 连续可信方向键即使早于下一次绘制，也累计请求位置；实际聚焦节点保留到目标接管焦点。导航模式仅当前单元格进入 Tab 顺序，有数据的滚动容器显式退出 Tab 顺序以抑制 Firefox 的自动入口，空网格保留入口；默认原生输入/按钮不额外增加入口；Enter/F2 进入编辑，Escape/F2 返回导航，编辑内保留输入自身方向键。输入所在行被外部数据删除后恢复有效单元格焦点，外部控件已经取得焦点时不抢回。自定义嵌套复合内容仍负责自己的键盘契约。RTL、远距离跳转、删项、重新测量及卸载释放仍由共享模型与浏览器回归验证。 |
| Chart | 组合取消键不关闭提示；正常 Escape 可关闭。保留键盘数据浏览、数据表替代、受控范围拒绝、数据删除后的焦点与选择修复、重复挂载和实时更新停止回归。 |
| Questionnaire / AsyncCollection | 排序组合确认键不启动或提交拖动，预览不发出答案。验证条件、跨题/异步校验、受控拒绝、动态数据、焦点恢复，以及请求版本、取消与卸载后晚到结果失效。 |

共享保护识别 `isComposing` 和 `keyCode === 229`，仅保护库自己的快捷键，不改变编辑器引擎原生输入模型；这不是本地化日期解析或完整操作系统输入法实现。四端调用同一 Kit 行为，适配层保留框架渲染、绑定和生命周期。

## 字体、颜色与窄屏


VirtualGrid 的固定行高内移除上下 padding，保留垂直居中与水平间距，避免字体仍能容纳时人为挤出内部滚动区。`rowSize` / `columnSize` 是调用方的尺寸契约，默认 48 / 160；多行、超大字号或复杂内容必须提供足够尺寸，并保留内容可访问性。库不会把内容高度自动回写成网格行高。

Drawer 在四方向 RTL 下聚焦输入、输入中文，将布局视口从 375×812 缩到 375×350，再恢复，检查输入可见、焦点和值保留、关闭后返回触发器。现有浏览器触摸协议检查拖动、取消及排序，减弱动效继续生效。

## 对照依据与限制

- ProseMirror View 的 input.ts：组合期间避免强制刷新；Safari 组合结束与 keydown 顺序需要保护。链接面板属于库自己的快捷键处理。
- CodeMirror View：组合 DOM 的复用、引擎历史和只读契约；已有挂载同步在组合期间避免重建编辑区。
- Zag dom-query 的 trackVisualViewport：优先监听 visualViewport，缺失时回退 window，并返回取消监听函数。Drawer 继续复用 Ark/Zag 的行为，模拟不能证明系统键盘实际定位。
- [WAI-ARIA Grid Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/grid/)：网格的导航/编辑状态、单一 Tab 游标和内部方向键导航，嵌入控件保留自身输入语义；语义快照保存名称、状态和绝对索引，不等于屏幕阅读器朗读结果。


真实 iOS/Android、VoiceOver/TalkBack/NVDA 和原生系统输入法尚未验收。字体 Token 放大不等于系统字体设置或浏览器原生200%缩放，缩小视口不等于软键盘，CDP 组合事务不等于原生输入法。
