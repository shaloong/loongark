# Chart：Linux 目视与行为验收

压力场景先使用原实现构建并截图，`before/` 保留真实桌面/375px、浅色/深色结果：完整长分类在分类轴重叠，千万级数值超出轴留白；三系列只交替使用两色，没有可见系列名称。基于这些证据完善共享模型与图例，API 与边界见 [图表说明](../../../chart.md)。

分类轴依据实际标签长度与容器宽度选择显示密度，长标签截短，原生 title 保留完整名称。数值轴使用紧凑/科学记数法与动态留白。点/柱提示加入系列名和原始值，SVG desc 提供数据说明；HTML 图例完整显示名称并在窄屏换行。默认 primary/mutedForeground 保持中性，第三系列使用已有 Shaloong vi.skyBlue，折线另用不同虚线辅助辨识。未增加调色板、Token 或依赖。

第一轮四端回归以实际 SVG getBBox 测量发现窄容器的标签间距不足，进一步修正密度和留白，未放宽裁切与重叠断言。随后暗色完整 Axe 发现图例进入白色背景；目视核验与几何测量确认 SVG 缺少内在尺寸，使 Stack 占位小于绘制尺寸，图表彼此重叠。补 width/height 并禁用图表 flex 收缩，修正自身布局而非增加背景遮盖问题。原始截图和失败日志保留于 `review-before-refinement/` 与 `logs/`。

最后复核改用 grapheme 保留组合字符，并按文字宽度估算减少过早截短；短分类尽量完整显示。缺少 Intl.Segmenter 的运行时保留完整提示并显示安全省略号，单独进程验证不会崩溃。

回归比较实际 computed fill，避免不同变量名最终呈现相同颜色。四端移动端截图另保存并比较像素。组合页的柱线切换、空数据/恢复、容器变宽/变窄、图例、长分类和缺失值在四端运行同一用例。

语义复核补齐空图表的 SVG desc，并加显式 aria-description 避免仅 desc 未被描述计算映射的问题，并使用真实无障碍描述断言验证本地化空提示和四端清空后的状态，不只检查可见文字。

null/缺失/非数值/非有限数据不转为 0：折线在缺失处断开，柱形不绘制缺失数据；全缺失显示空状态。真实模型测试覆盖极大正负值、有限坐标、空状态转义和 150,000 行数组归约，避免旧实现的参数展开异常。SSR 检查四端描述、图例和极值；容器观察器沿用各端卸载清理。

人工查看桌面/手机浅深色组合页，以及四端手机图；自动验收所有 266 Story 的默认展示与专项交互，未声称逐张人工检查全部自动图片。测量与结果见 [acceptance.json](acceptance.json)。自动截图使用 tar.gz 归档，解压可恢复原路径；人工图、四端图和测量 JSON 直接保留。

新增四张 Chart Linux 基线，在人工查看后初始化，再通过普通比较回归。原有十张 Linux 和两张 Windows 基线不覆盖。系统 Chromium 151.0.7922.173 与 Playwright 1.57.0；固定 Chromium 143 下载受环境网络策略限制，不声称系统浏览器或 Linux 字体与固定浏览器、Windows 像素一致。

当前 Chart 为信息展示，不提供缩放/刷选/实时流或第三方引擎兼容；原生提示/描述不等于交互提示，可组合 DataTable 提供逐行键盘阅读。三种默认颜色循环，超过三系列可显式指定既有 Token 或合法颜色。未测试全部 peer 版本、Firefox/WebKit、真实手机或屏幕阅读器。
